# Changelog

All notable changes to AEmulator Pro will be documented in this file.

## [0.0.0.3.15] - 2026-11-17
### Added
- Changelog activity integrated into settings.
- Android 1.0 support and HTC boot profile.
- Background toggle option for the Floating Action Button (FAB) menu.

### Updated
- Refactored API update functionality and settings.
- Removed VM session tab bar from the interface for a cleaner home view.

---

## [0.0.0.3.14] - 2026-11-10
### Added
- Split-screen VM tab management and drag-to-split gesture support.
- Dedicated language selection page with comprehensive localization.

### Improved
- Memory management and low-memory killer (LMK) policies for background VMs.
- Audio HAL implementation and microphone bridge routing.

---

## [0.0.0.3.13] - 2026-11-01
### Added
- Material 3 adaptive UI layouts and tablet navigation rail support.
- Device emulation skins for Wear OS, TV, and desktop form factors.

### Fixed
- Camera HAL fallback and preview resolutions.
- Storage permission handling on Android 13+.

---

## [0.0.0.3.12] - 2026-10-20
### Added
- ROM catalog downloader with progress bar indicators.
- Custom color picker and theme customization settings.

### Updated
- Core execution engine and guest kernel patch integration.
